# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Thank you for your interest in contributing to the **Simple Interest Calculator** project!

## How to Contribute

### 1. Fork the Repository
Click the **Fork** button at the top right of this repository page to create your own copy.

### 2. Clone Your Fork
```bash
git clone https://github.com/<your-username>/git-github-final-project.git
cd git-github-final-project
```

### 3. Create a Branch
```bash
git checkout -b my-new-feature
```

### 4. Make Your Changes
Work on your bug fix, documentation improvement, enhancement or new idea.

### 5. Commit Your Changes
```bash
git add .
git commit -m "Describe your change here"
```

### 6. Push to Your Fork
```bash
git push origin my-new-feature
```

### 7. Open a Pull Request
Open a pull request from your forked repository to the original repository, and describe the change you made.

## Guidelines
- Keep pull requests small and focused.
- Write clear commit messages.
- Make sure your code runs before submitting.
- Be respectful and follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting Bugs
Open a GitHub issue with:
- Steps to reproduce the bug
- Expected behaviour
- Actual behaviour
- Your environment (OS, shell version)

## Suggesting Enhancements
Open a GitHub issue describing your idea, why it is useful, and how it could be implemented.
